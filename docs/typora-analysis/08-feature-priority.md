# 08 功能优先级

优先级针对即将独立编写的个人 Markdown 编辑器。它参照 Typora 1.14.10 里已经证实的能力，不把未知交互写成必须项。

证据来自 `01` 到 `07`。等级沿用那一组定义。

## P0：没有这些就不构成编辑器

目标是打开、编辑、保存、再打开，内容一致。

| 功能 | 对应的 Typora 证据 | 实现要点 | 验收 |
| --- | --- | --- | --- |
| 桌面窗口与单一编辑区 | Cocoa 窗口 + `#write` | Electron + Vue 壳，居中书写栏 | 启动后能聚焦并输入 |
| 块级所见即所得 | `#write` textbox，块模板 | Tiptap | 标题、段落、列表、引用、强调、链接可编辑 |
| 源码往返 | 源码模式与序列化痕迹 | Tiptap Markdown 序列化，外加固定测试稿 | 保存后再打开，测试稿字节级或规范化后一致 |
| 打开与保存 | `Document`、Markdown UTI | 原生文件对话框，UTF-8 | 取消对话框不改当前文档 |
| 脏标记与自动保存 | `autosavesInPlace`、`hasUnautosavedChanges` | 防抖写盘，先写临时文件再替换 | 杀进程后最多丢失一个防抖间隔 |
| 撤销与重做 | 主包大量 undo 字符串；行为未验证 | 使用 Tiptap history | 连续输入、撤销、重做不丢相邻段落 |
| 代码块与表格 | 表格对话框、CodeMirror 模式 | Tiptap 表格与代码块节点 | 2×2 表格、围栏代码块往返不丢单元格 |
| 本地图片 | `insertLocalImage`、相对路径提示 | 粘贴 PNG/JPEG 到文档旁 `assets/`，写入相对路径 | 移动整个文件夹后图片仍显示 |
| 文件侧栏 | `#file-library` | 打开一个文件夹，显示 Markdown 文件 | 点选切换文件；有未保存内容时先保存或确认 |
| 基础快捷键 | 原生命令类存在，键位未知 | 自定一套：保存、加粗、标题、列表、撤销 | 快捷键与工具按钮结果相同 |

P0 明确不做：聚焦模式、打字机模式、Mermaid、数学、PDF、Pandoc、主题市场、全局内容搜索。

## P1：日常写作会反复用到

| 功能 | 证据 | 实现要点 |
| --- | --- | --- |
| 大纲 | `#outline-content`，`togglePanel('outline')` | 从文档标题生成，点击滚动到节点 |
| 查找替换 | 查找图标含大小写、整词、正则 | 编辑器内搜索，正则错误要可见 |
| 源码模式 | `toggleSourceMode`，`#typora-source` | CodeMirror 6 整篇切换，退出前解析失败则留在源码并标出行 |
| 主题 | 六个 CSS 主题 + 用户 CSS 槽 | 两套自有主题（浅色、深色）和一份用户 CSS 路径 |
| 最近文件 | `quickOpen.*Recent*` | 本地 JSON，最多 20 条 |
| 外部修改提示 | `DocumentFileWatcher`、`DocumentSnap` | 比较 mtime 与自己的写入时间 |
| HTML 导出 | `copyAsHTMLSource`、无样式 HTML | 用当前 Markdown 渲染，不嵌入应用私有类名 |
| PDF 导出 | `TyPDFEngine` | Electron 打印到 PDF |
| 图片管理 | 复制、移动、存储位置设置 | 设置里可选资源目录名；未保存时禁止相对路径复制并说明原因 |
| 崩溃恢复 | 自动保存选择子，恢复策略未知 | 保留一次临时副本，启动时若比目标文件新则提示 |

## P2：完整度，不阻塞日常使用

| 功能 | 证据 | 说明 |
| --- | --- | --- |
| 数学 | MathJax 4 被页面加载 | 行内与块级。先保证美元分隔符往返 |
| Mermaid | 独立脚本与 CSS | 失焦后渲染，编辑时显示源码 |
| 聚焦与打字机 | 原生直接调用两个 toggle | 只改滚动和透明度，不改文档 |
| 脚注、任务列表 | 主包字符串与 CodeMirror 列表正则 | 放进往返测试 |
| 文件夹内容搜索 | 随包 ripgrep | 可以作为可选命令，不内嵌 Typora 的 `rg` 二进制 |
| Word / EPUB | 需要外部 Pandoc | 检测 `pandoc`，没有就显示安装说明，不打包 Pandoc |
| 自定义协议与图床 | `typora://`、iPic | 个人版用文件路径即可，不做图床 |
| 插件 | 未见开放插件 API 的证据 | 先留命令注册表，不设计第三方加载 |

## 不纳入

这些在制品里存在，但属于 Typora 产品设施，个人编辑器不实现：

- Sparkle 更新与许可证窗口
- iPic 上传与 YAML 自动上传
- AppleScript、触控栏
- TextBundle 作为默认容器（P2 可再评估）
- 复制 Typora 主题、图标、协议名和文案

## 模块划分（供确认后开发）

| 模块 | 职责 |
| --- | --- |
| `shell` | Electron 窗口、菜单、对话框 |
| `documents` | 打开的文件、脏标记、自动保存、最近文件 |
| `editor` | Tiptap 文档、命令、序列化 |
| `source` | CodeMirror 源码模式 |
| `files` | 文件夹树 |
| `outline` | 标题导航 |
| `assets` | 图片目录与相对路径 |
| `theme` | 浅色、深色、用户 CSS |

数据结构的最小形状：

- `DocumentSession`：`path`、`markdown`、`savedMarkdown`、`dirty`、`mtime`、`assetDir`
- 编辑器内部以 Tiptap JSON 为工作副本，保存边界只认序列化后的 Markdown 字符串
- 比较「再打开是否一致」时比较 Markdown 字符串，不比较 JSON

## 测试门槛

P0 完成前准备 12 份固定 Markdown，覆盖：

1. 空文件
2. 只有标题和段落
3. 嵌套列表与任务列表
4. 引用里的列表
5. 链接与行内代码
6. 围栏代码块，含语言标记
7. 有对齐的表格
8. 表格单元格内的行内格式
9. 本地相对图片
10. 混合顺序：标题、列表、代码、表格
11. 连续空行与行尾空格
12. 非 UTF-8 失败样本（应拒绝或明确转码，不能静默写坏）

每份都走：打开 → 在末尾加一个段落后撤销 → 保存 → 重新打开 → 与期望 Markdown 比较。

P1 再增加查找、源码模式来回切换、主题不影响字符串、外部修改提示。P2 增加数学和 Mermaid 的源码保留测试。

补充结论见 `09-supplement-runtime-and-modules.md`。标记显隐可以参考「独立标记节点 + 焦点类」，自动保存不要照搬页面里那个仅 Node 宿主使用的 10 分钟定时器。macOS 实际写盘间隔仍未测到。
