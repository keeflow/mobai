为一个人写字准备

打开本地文件，专心编辑。工具够用，界面安静。

  • 双模式编辑

    所见即所得与源码模式随时切换，表格、公式、Mermaid 图一并照顾。

  • 本地文件库

    打开单个 Markdown 或整个文件夹，侧栏文件、大纲、最近记录与文件夹搜索。

  • 写作节奏

    聚焦模式、打字机滚动、查找替换、字数统计，浅色 / 深色主题随手切换。

  • 稳妥落盘

    原子写入、自动保存、外部修改检测与崩溃恢复。图片可落到文档旁资源目录。

  • 导出与打包

    导出 HTML、PDF；可选 Pandoc 导出 Word / EPUB / LaTeX。支持 TextBundle。

  • 没有插件墙

    命令与菜单是静态列表。不加载第三方插件，也不绑定任何云账号。
